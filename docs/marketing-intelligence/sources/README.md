# Sources

Optional: raw reference material backing a case study — a saved screenshot
of the original report, an exported PDF, etc. — when the live `sourceUrl` in
a case study might later go dead or paywall. Not required for a case study
to be valid; `sourceUrl`, `sourceTitle`, `publisher`, and `dateAccessed` in
the case study's own JSON file are the required, minimum trace back to the
evidence.

If you add a reference file here, name it after the case study's `id` (e.g.
`meta-free-inspection-2025-acme.pdf`) so it's easy to match back up.
